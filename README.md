# 抢滩登陆：现代战争

浏览器里的海岸炮塔防守射击游戏。单个 `index.html`，无需安装，直接打开即可游玩。

- **经典模式**：每波结束后在商店购买升级
- **肉鸽模式**：击落随机空投的补给箱，三选一获得强化
- 每 10 波一场 Boss 战，按 N 发射战术核弹

操作：鼠标瞄准，左键机枪，右键/Shift 机炮，空格导弹，Q 空袭，N 核弹，P 暂停，M 静音。

# AC-130 空中死神（`ac130.html`）

复刻《使命召唤》AC-130 炮艇机关卡：热成像视角盘旋在村庄上空，用 105 / 40 / 25 毫米火炮掩护地面小队（带红外频闪的是友军）推进到撤离点。

- 105mm 大范围、装填慢；40mm 中等；25mm 连射会过热。炮弹有飞行时间
- 敌人：步兵、RPG、武装皮卡、装甲车、单兵防空导弹（按 F 投放干扰弹）
- **夜间任务**：经典热成像；**白天任务**：彩色电视摄像机 + 阳光阴影，友军靠橙色识别板辨认，T 可切换彩色/白热/黑热
- 误伤 2 名友军、小队全灭或飞机被击落都会任务失败；过关后进入更难的下一关
- 关数越高，炮组越熟练：装填速度每关 +18%（第 5 关约 ×1.7，最高 ×2.1）
- 敌人强度第 6 关后放缓（每关只按 30% 幅度增长），RPG 占比上限 26%，RPG/装甲车炮弹对友军伤害 ×0.6；丧尸围城每波 +7%（最高 ×1.8）

暂停菜单里列有全部快捷键。操作：准星跟随鼠标，按住右键拖动或 WASD 平移镜头（鼠标贴住屏幕边缘也会平移），C 回到友军，左键/空格开火，右键、1/2/3 或滚轮切换火炮，F 干扰弹，T 切换传感器，WASD 平移，P 暂停，M 静音，N 开关飞机嗡鸣声（菜单和暂停界面也有开关），R 快速装填（击杀攒满后，12 秒内装填 ×2.5）。暂停菜单可停用 25mm 机炮，只用 105 和 40mm。手机：拖动屏幕瞄准，右下按钮开火。

### 丧尸围城模式

主菜单「丧尸围城」（夜间）或「丧尸围城 · 白天」：6 名幸存者守在镇中心营地，丧尸（普通、奔跑者、大块头）一波接一波从房屋和四面八方涌来，无尽波次，营地被攻破即结束，记录坚守波数。
本模式多一门**燃烧弹**（按 4，手机上替换干扰弹按钮）：落地后烧出一片火海约 11 秒，走进去的丧尸会着火，大块头也怕火。热成像里丧尸是冷的（偏灰），着火后发白。误伤 3 名幸存者失败。
